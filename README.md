# Soil Health Zonation Pipeline

This repository contains an end-to-end data processing, clustering, and anomaly detection pipeline designed to classify roughly 200,000 Indian villages into distinct agronomic soil health zones and identify localized soil anomalies. The pipeline consumes raw Soil Health Card (SHC) datasets and produces a deterministic, reproducible stratification of villages into four primary agronomic environments (Saline, Micronutrient-Deficient, Acidic/High-N/OC, and Generally Fertile). It uses a hybrid approach (domain-rule + K-Means clustering) to overcome the variance-minimization bias of standard clustering algorithms, followed by multi-radius DBSCAN and localized z-scoring to detect complex, compound soil problems.

## Folder Structure

*   `src/`: Contains all Python scripts for the pipeline.
    *   `build_pipeline.py`: The canonical, consolidated pipeline script that orchestrates data loading, imputation, feature scaling, and the hybrid zonation.
    *   `anomaly_detection.py`: Runs DBSCAN and Local Anomaly Score (LAS) computations on the processed zones to flag outlier villages.
    *   `explainability.py`: Generates human-readable explanations for anomalous/saline villages (under development).
    *   `test_*.py`: Various stability and validation scripts used during methodology design.
*   `data/`: Contains raw and processed datasets (ignored by git due to large sizes).
*   `outputs/`: Stores figures, reports, and validation tables generated by the pipeline.

## Reproducing the Pipeline

**Note:** The `data/` and `outputs/` directories are strictly excluded from version control due to large file sizes (>1GB raw). The pipeline is completely reproducible locally once the raw dataset is staged.

1.  **Download Raw Data:** Download the raw "Soil Nutrient Analysis 2024-25" dataset from the India Data Portal. 
2.  **Stage Data:** Place the downloaded CSV into `data/raw/soil-nutrient-analysis.csv`.
3.  **Run Pipeline:** Execute the primary pipeline script to clean, impute, and zone the data:
    ```bash
    python src/build_pipeline.py
    ```
4.  **Run Anomaly Detection:** Execute the anomaly detection module on the processed zonation output:
    ```bash
    python src/anomaly_detection.py
    ```

## Key Findings

Because the generated datasets and reports are too large to host on GitHub, the core scientific findings derived from the validated pipeline runs are summarized below:

*   **Zonation Distribution:** The 197,444 villages cluster tightly into four stable zones: Generally Fertile (~50.5%), Acidic/High-N/OC (~34.2%), Micronutrient-Deficient (~10.6%), and Saline (~4.7%).
*   **Methodological Stability (Clustering):** Pure variance-minimization clustering (Ward/K-Means) systematically fails to isolate the critical minority Saline population. A hybrid approach using an agronomically defined threshold (`ec_pct_non_saline < 0.7`) to extract the Saline population, followed by K-Means (K=3) on the residual, achieves third-decimal-place stability across multiple random seeds.
*   **Anomaly Profile:** Global anomalies (DBSCAN at eps=2.533) account for just 0.56% of the data. Crucially, 86% of all global anomalies are concentrated strictly within the Micronutrient-Deficient and Saline zones, highlighting that extreme multidimensional soil failures are not randomly distributed but stack upon existing systemic deficiencies.
*   **Local Anomalies (Module 9):** Approximately 13.7% of villages appear mathematically "normal" at a national level but deviate severely (>3 standard deviations) from the immediate geographic mean of their host district or state. This validates the need for local-scale spatial monitoring.
*   **DBSCAN Operational Limits:** On a standard workstation, executing 13-dimensional DBSCAN (k-d tree) across 197k points hit hard memory limits (`MemoryError`) at a search radius of eps=2.786 (+10% baseline). The computationally viable optimal radius was derived at the 98th percentile k-distance (eps=2.533). Jaccard overlap stability tests on a 50k subsample showed ~55% overlap across varying $\epsilon$ radii, confirming that while anomaly rates remain low, the classification boundary in high-dimensional soil space is highly sensitive to radius expansion.
